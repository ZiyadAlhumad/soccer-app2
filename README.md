# Soccer App

A full-stack soccer booking/management web application built using React, Node.js, Express, and MongoDB.

## Features
- User registration and login
- Stadium management
- Reservations
- Admin dashboard
- Messages
- Statistics

## Technologies Used
- React
- Vite
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## How to Run
Backend:
bash
cd backend
npm install
npm run dev
front : 
cd frontend
npm install
npm run dev
